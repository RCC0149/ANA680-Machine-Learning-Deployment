# ANA 680 – Machine Learning Deployment

**Author:** Randall Crawford  

---

## Course Overview

ANA 680 – *Machine Learning Deployment* focuses on the **end-to-end lifecycle of deploying machine learning models into production environments**. The course bridges the gap between model development and real-world deployment by emphasizing **MLOps principles**, **DevOps workflows**, and **cloud-based deployment strategies**.

Students explore the tools, processes, and infrastructure required to reliably deploy, monitor, and maintain machine learning systems at scale, with hands-on exposure to industry-standard platforms and practices.

---

## Course Objectives

The primary objectives of this course are to:

- Examine the full **machine learning application lifecycle**
- Understand the role of **DevOps and MLOps** in production ML systems
- Compare and contrast **ML deployment strategies**
- Deploy machine learning models to **cloud environments**
- Optimize deployed models for **performance and reliability**

---

## Learning Outcomes

Upon successful completion of the course, students are able to:

- Investigate and explain key components of the ML lifecycle  
- Compare multiple deployment architectures and tools  
- Deploy machine learning models in cloud environments  
- Integrate CI/CD workflows for automated testing and deployment  
- Apply monitoring and optimization techniques to deployed models  

These outcomes align with the program-level objectives of applying Python for AI/ML, evaluating models, and deploying ML solutions in production environments :contentReference[oaicite:1]{index=1}.

---

## Topics Covered

Key topics explored throughout the course include:

- Machine learning lifecycle and MLOps workflows  
- Flask-based model serving and API development  
- Continuous Integration and Continuous Deployment (CI/CD)  
- Containerization with Docker  
- Cloud deployment using Heroku and AWS  
- Model deployment with AWS SageMaker  
- Monitoring and maintenance of deployed ML systems  
- Kubernetes-based orchestration and scaling  

---

## Tools & Technologies

The course emphasizes practical, hands-on experience with widely used tools and platforms, including:

- **Programming & Analysis:** Python, Jupyter Notebooks  
- **Web Frameworks:** Flask  
- **Version Control & CI/CD:** Git, GitHub, GitHub Actions  
- **Containerization:** Docker, Docker Hub  
- **Cloud Platforms:** Heroku, AWS (SageMaker)  
- **Orchestration:** Kubernetes, Minikube  

Students are encouraged to justify and select appropriate tools for each stage of the ML lifecycle rather than following a single prescribed stack :contentReference[oaicite:2]{index=2}.

---

## Course Structure

The course is organized into four primary modules:

1. **Machine Learning Lifecycle & Foundations**  
2. **Deployment and Automation in ML Pipelines**  
3. **Containerization and Cloud-Based Deployment**  
4. **Monitoring and Deployment with AWS SageMaker**

Assessment includes homework assignments, quizzes, a midterm exam, and a **comprehensive final project** that integrates all course concepts into a fully deployed ML system.

---

## Final Project

The final project serves as a capstone experience, requiring students to:

- Select a real-world dataset  
- Perform data preparation and model training  
- Deploy the model using production-style workflows  
- Implement CI/CD, containerization, and cloud deployment  
- Demonstrate the deployed system  

The project emphasizes **practical MLOps execution** rather than theoretical modeling alone :contentReference[oaicite:3]{index=3}.
